# Plan: Blueskyで開くボタンの実装

## 概要
投稿のステータスが「投稿済み」(posted) の場合に、Blueskyで開くボタンを投稿カードに配置する機能を実装します。

## 現在の状態の分析
- `ScheduledPost` モデルには `post_uri` フィールドが既に存在
- `posts.js` の `createPostCard` 関数で投稿済みの場合に `blueskyLinkHtml` を生成するコードが一部実装済み
- しかし実際のUIにはボタンが表示されていない

## 実装タスク

### 1. JavaScriptの修正 (posts.js)
- `createPostCard` 関数内の `blueskyLinkHtml` 生成ロジックを修正
- 投稿済みかつ `post_uri` が存在する場合にボタンを表示
- ボタンのスタイリングと配置位置を調整

### 2. CSSスタイルの追加 (bluesky.css)
- Blueskyリンクボタンの専用スタイルを追加
- 既存のアクションボタンとの視覚的統合
- レスポンシブデザイン対応

### 3. HTMLテンプレートの確認 (posts.html)
- 投稿カードの構造が正しくレンダリングされることを確認
- ボタン配置のためのDOM構造を確認

### 4. イベントハンドラの追加
- Blueskyリンクボタンのクリックイベント処理
- 新しいタブでBlueskyの投稿ページを開く機能

## 詳細な実装手順

### タスク1: JavaScriptの修正

**ファイル**: `app/static/js/bluesky/posts.js`

**修正内容**:
- `createPostCard` 関数内の `blueskyLinkHtml` 変数を修正
- 投稿ステータスが `posted` かつ `post.post_uri` が存在する場合のみボタンを表示
- ボタンのHTML構造を改善

**変更例**:
```javascript
let blueskyLinkHtml = '';
if (post.status === 'posted' && post.post_uri) {
    blueskyLinkHtml = `<a href="${escapeHtml(post.post_uri)}" target="_blank" rel="noopener noreferrer" class="btn btn-sm btn-outline-info bluesky-link-btn" title="Blueskyの投稿ページを開く"><i class="fas fa-external-link-alt"></i><span>Blueskyで開く</span></a>`;
}
```

### タスク2: CSSスタイルの追加

**ファイル**: `app/static/css/bluesky.css`

**追加内容**:
- `.bluesky-link-btn` クラスのスタイル定義
- アイコンとテキストの配置調整
- ホバー効果の追加

**スタイル例**:
```css
.bluesky-link-btn {
    display: inline-flex;
    align-items: center;
    gap: 0.25rem;
    white-space: nowrap;
}

.bluesky-link-btn:hover {
    background-color: rgba(29, 161, 242, 0.1);
    border-color: var(--primary-color);
}
```

### タスク3: HTML構造の確認

**ファイル**: `app/templates/bluesky/posts.html`

**確認事項**:
- `posts-container` の構造が正しいこと
- 投稿カードのレンダリングが期待通りに行われること
- ボタン配置のための `post-actions-row` が存在すること

### タスク4: イベントハンドラの実装

**ファイル**: `app/static/js/bluesky/posts.js`

**追加内容**:
- Blueskyリンクボタンのクリックイベント処理
- 新しいタブでURLを開く標準的な動作
- アクセシビリティ対応（キーボード操作など）

## テスト計画

### 単体テスト
- 投稿ステータスが `posted` の場合にボタンが表示されること
- `post_uri` が存在しない場合にボタンが表示されないこと
- ボタンのクリックで新しいタブで正しいURLが開かれること

### 統合テスト
- 実際の投稿済み投稿でボタンが機能すること
- フィルタリング機能とボタンの表示が連動すること
- レスポンシブデザインでの表示確認
